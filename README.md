# Остров 2.0

Первый прототип ядра по [спецификации v1.2](docs/specification.md).
Python 3.12+, SQLite из стандартной библиотеки; внешние зависимости не нужны.
Команды выполняются из корня репозитория на Windows или Linux:

```sh
python -m unittest discover -s tests -v
python -m ostrov --seed 42 --seconds 4000 --save world.sqlite3
python -m ostrov --load world.sqlite3 --seconds 100
python -m ostrov --gui
```

В Linux при необходимости используйте `python3` вместо `python`.

Реализованы непрерывная геометрия с неровной границей, постоянная зона 30 м,
начальная Росмонтис, размещение существ наблюдателем, смертельное падение,
лимит 10 активных существ, игровое время и пауза, фазы сдвига, замена внешней
границы и транзакционные сохранения SQLite. Завершённый мир можно загрузить
для просмотра, продолжить его развитие нельзя. Состояние RNG сохраняется.

Графический наблюдатель на Tkinter показывает карту, дуб, постоянную зону,
существ и фазы сдвига. Доступны пауза, скорости ×1/5/10/100, выбор существа,
просмотр состояния, памяти, инвентаря и отношений, создание существ у дуба,
журнал мира, новый мир, сохранение и загрузка. ЛКМ выбирает существо,
ПКМ переносит выбранное в указанную точку; смертельный перенос требует
подтверждения. Новый и загруженный мир открывается на паузе.
На Windows установите Python с компонентом Tcl/Tk (обычно включён).
На Linux для окна нужны Tkinter и графический дисплей; в облачной среде
можно использовать консольный режим. GUI-тесты требуют дисплея и иначе
помечаются как пропущенные.

Это прототип, не готовое приложение. Пока отсутствуют полноценные потребности,
цели, бой, поиск пути и столкновения, река, предметы и постройки на карте,
генерация прибывающих существ и миров, карточки персонажей и события.
Метод `move` служит размещению наблюдателем, а не моделированию пути.
Состояние хранится версионированным JSON-снимком в SQLite; отдельные таблицы
истории и запросов API будут добавлены вместе с соответствующими подсистемами.

Временные решения: ×1 — одна игровая секунда за реальную; интервалы сдвига
равномерны от 1 до 3 игровых часов, предупреждение — за 1–5 минут;
последние 30 секунд выделены под растворение. Новые существа не получают
знание о безопасной зоне. Нахождение Росмонтис вне постоянной зоны в момент
сдвига завершает мир как утрата главного персонажа. Эти решения требуют
уточнения при развитии механик. Никакие характеристики её способностей
не выдумываются вместо отсутствующей карточки.

## DeepSeek — решения существ

Откройте `python -m ostrov --gui` → **Настройки DeepSeek**. Укажите ключ,
включите DeepSeek и нажмите **Применить**, затем **Продолжить**.
Ключ можно заранее задать переменной `DEEPSEEK_API_KEY`; приложение подставит
его в настройки. Ключ хранится только в памяти процесса, не в SQLite,
журналах или репозитории. После перезапуска подключение нужно включить заново.
Запросы идут только на `https://api.deepseek.com/chat/completions`.

Модель предлагает каждому активному существу одно действие: ожидание,
шаг до 2 метров или реплику до 500 символов. Python проверяет весь пакет
до применения: неизвестные существа, дополнительные поля и изменение
физических правил отклоняются. Путь шага проверяется на падение; реплики
запоминаются активными существами в радиусе 15 м. Это начальный набор
действий, не полноценная боевая система или модель характера Росмонтис.

Погрешности формата (регистр `type`, числовые строки dx/dy, неиспользуемые
поля dx/dy/text со значением null или пустой строкой) нормализуются.
Слишком длинное конечное смещение до 1 000 000 м по каждой оси трактуется
как направление: движок ограничивает его одним шагом до 2 м. Это не перенос
к указанной точке. Изменения отмечаются в журнале DeepSeek. Неизвестные
действия, лишние содержательные поля, нечисловые координаты и слишком
длинные реплики по-прежнему отклоняются. Ошибка показывает номер действия
и нарушенное правило; отклонённый ответ (до 8000 символов, ключ скрыт)
сохраняется в журнале для диагностики. Ошибка не вызывает платных повторов.

Запрос выполняется в фоновом потоке, интерфейс остаётся доступен.
На время ответа игровое время останавливается. Ошибка API, тайм-аут
или неверный ответ ставят мир на паузу; **Продолжить** запускает новую
попытку. Автоматических платных повторов нет. Интервал (по умолчанию 10
реальных секунд после ответа) не зависит от ×1/5/10/100. С выключенным
DeepSeek доступен ручной режим наблюдателя без автономных решений.
Состояние существ, память, активный лор и инструкции отправляются провайдеру.
Контекст группы общий; это не изолированные приватные агенты.
История запросов (контекст и разобранные ответы) сохраняется в SQLite и
показывается в отдельном журнале DeepSeek. Смена мира/настроек отбрасывает
устаревшие ответы; старые сохранения ядра остаются совместимыми.

## Лорбуки NeraAI

Кнопка **Лорбуки / инструкции** открывает JSON-редактор для выбранного
существа и глобальных записей текущего мира. Второй режим — отдельные
**Инструкции модели**. Есть создание записей, импорт, экспорт и изменение
JSON. Удалите объект из массива для удаления записи; `enabled: false`
отключает её. Нажмите **Применить**, затем сохраните мир в SQLite.
Импорт добавляет записи, отклоняет повторяющиеся `id` и не меняет исходный
текст `content`. Совместимый с NeraAI пример:

```json
[
  {
    "id": "old-oak",
    "keys": "дуб; дерево",
    "content": "У дерева тёмная кора.",
    "enabled": true,
    "alwaysActive": false,
    "global": true
  }
]
```

Перенесены правила NeraAI: поиск подстроки без учёта регистра, разделители
ключей `,`, `;`, перенос строки; `alwaysActive`; отключение через `enabled`;
локальные записи перед глобальными; устранение дубликатов внутри области;
лимит активного текста 12 000 единиц UTF-16. Для активации сканируются
последние 12 реплик и общее описание мира. Содержимое самих лорбуков
рекурсивно не сканируется. Без ключей и без явного `alwaysActive` запись
становится постоянной, как при JSON-импорте в NeraAI.
Лимиты импорта: 400 записей, 2 000 000 единиц UTF-16 на JSON; длины
`id`/`keys`/`content`: 100/2000/30000. Отсутствующий `id` генерируется.

Адаптация к симуляции: локальная область — существо вместо карточки чата;
глобальная — все существа **текущего сохранённого мира**, не другие миры.
История — реплики действий `say` вместо сообщений чата. Формат записей
и основные правила совместимы; Android-интерфейс NeraAI не копируется.
Инструкции модели задают стиль и пожелания, лор хранит сведения о персонажах
и мире. Ни один слой не может переписать физику или контракт действий.
Режим 18+ не реализован и не включается импортом инструкций.
